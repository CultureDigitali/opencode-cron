# TRAE unifica Code e Work in un'unica piattaforma con Agent e IDE modes

- **Fonte**: AI News Feed (da report QuantumBit)
- **URL**: https://ainewsfeed.tech/articles/trae-merges-code-and-work-into-unified-platform-with-agent-and-ide-modes-27765-en-us-v1/
- **Pubblicato**: 2026-10-09T12:54:09Z

## Riassunto
Il 9 ottobre 2026 TRAE ha fuso TraeCode e TraeWork in un unico prodotto "TRAE": **Agent mode** (workbench globale per gestire progetti e più agent in parallelo in una finestra: coding, documentazione, delivery) e **IDE mode** (SOLO/IDE per il lavoro di coding profondo). Obiettivo: pipeline completa idea→delivery senza spezzare il contesto tra tool separati.

## Fatti chiave
- Multi-agent workflow in un'unica finestra; sidebar mostra dove le task sono bloccate.
- Artefatti condivisi, template, accesso via Feishu/WeChat; desktop/web/mobile sincronizzati.
- Test QuantumBit: benefici in multi-agent coding, doc, test e regressione; problemi di coordinamento quando gli agent girano in parallelo.
- Trend di settore confermato: Cursor 3 (Agents Window, aprile), Claude Code (Agent View) — tutti integrano agent management + code editing nello stesso tool.

## Perché conta
Segnala lo shift di prodotto da "un agente che scrive codice" a "orchestrazione di gruppi di agent da idea a delivery".
