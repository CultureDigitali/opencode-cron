# AI coding agents generate more code, but not more software

- **Fonte**: Ars Technica (Kyle Orland)
- **URL**: https://arstechnica.com/ai/2026/10/ai-coding-agents-generate-more-code-but-not-more-software/
- **Pubblicato**: 2026-10-09T19:43:50Z

## Riassunto
Studio Harvard (Chen & Stratton) su dati Jellyfish: 300M di "work events", 700k+ dipendenti, 700+ firme software (2021 → marzo 2026). L'introduzione di AI coding agents porta a +30% righe di codice, +20% commit, +23% PR, ma **nessun aumento statisticamente significativo della risoluzione di Issue/Epics** (output software reale). Il collo di bottiglia è il code review umano: tempo medio review→merge +49%, PR con changes requested quasi raddoppiate, commenti per PR +35%.

## Fatti chiave
- Nessuna evidenza di riduzione dell'occupazione attribuibile all'AI.
- +14% di lavoratori dedicati al code review dopo l'introduzione degli agent.
- A marzo 2026, l'80% delle firme usa qualche forma di AI code review, ma gli agent AI generano solo il 23,3% dei commenti di review e il 10,8% delle PR.
- 95% delle firme nello studio ha adottato AI coding agents.

## Perché conta
Conferma il pattern "coding più veloce ≠ shipping più veloce": i guadagni di scrittura vengono assorbiti dal review bottleneck. Impatto diretto su come valutare il ROI degli agent.
